```sql
-- src/db/schema.sql.ts:352 / schema/001_schema_v2.sql:335 / schema/002_migration_v1_to_v2.sql:129
```

### ★★ 登记 3 的前提被推翻的**完整证据链**

1. `schema` 三处一致建了 `UNIQUE INDEX ... (memory_id)` ⇒ **一记忆只属一细桶** ⇒
2. ⇒ 同批桶内 `COUNT(DISTINCT memory_id)` **恒等于** `COUNT(*)` ⇒
